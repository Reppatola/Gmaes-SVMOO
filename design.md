# Дизайн-система для MMO Strategic Survival Sandbox

## Философия дизайна

### Визуальный язык
- **Темная постапокалиптическая эстетика** с элементами технологичного хаоса
- **Кинематографичность** через глубокие тени, драматичное освещение и слоистые композиции
- **Индастриальный минимализм** - чистые формы с техническими деталями
- **Атмосфера выживания** через грубые текстуры, ржавчину и следы разрушения

### Цветовая палитра
- **Основной фон**: Глубокий угольный (#0a0a0a) и темно-серый (#1a1a1a)
- **Акцентные цвета**: Оранжево-красный (#ff4444) для угрозы, зеленый (#44ff44) для безопасности
- **Вторичные цвета**: Темно-синий (#1e3a8a), бурый (#92400e)
- **Текст**: Белый (#ffffff) и светло-серый (#e5e5e5)

### Типографика
- **Заголовки**: Impact, Unna - жирные, выразительные шрифты для драматичности
- **Основной текст**: Quattrocento Sans, Liter - чистые, технические шрифты для читаемости
- **Акценты**: Использование моноширинных шрифтов для технической информации

## Визуальные эффекты

### Используемые библиотеки
- **Anime.js**: Плавные анимации элементов и переходов
- **Shader-park**: Кастомные шейдеры для фоновых эффектов
- **PIXI.js**: Частицы и визуальные эффекты для системы шума
- **ECharts.js**: Интерактивные графики для статистики и аналитики
- **Splide.js**: Карусели для скриншотов и контента

### Эффекты и анимации
- **Параллакс фон**: Движущиеся слои для создания глубины
- **Шейдерные фоны**: Анимированные текстуры с эффектами дыма/огня
- **Частицы**: Система частиц для визуализации угрозы и активности
- **Glitch эффекты**: Для эстетики цифрового хаоса
- **Плавные переходы**: Между секциями и состояниями

### Компоненты интерфейса
- **Навигация**: Темная панель с эффектами подсветки
- **Кнопки**: Индустриальный стиль с анимацией наведения
- **Карты**: Темные темы с цветовой индикацией зон
- **Модальные окна**: Полупрозрачные с размытием фона
- **Прогресс-бары**: Технический стиль с анимацией заполнения

## Адаптивность
- **Desktop**: Полноценные эффекты и анимации
- **Tablet**: Оптимизированные интерактивные элементы
- **Mobile**: Упрощенные версии компонентов, сохраняя функциональность
