## Основные интерактивные элементы:

### 1. Интерактивная карта мира
- Квадратная сетка мира с различными зонами безопасности (1.0-0.0)
- Кликабельные территории с информацией о контроле кланов
- Динамическое отображение уровня угрозы (цветовая индикация)
- Всплывающие подсказки с детальной информацией о каждой зоне

### 2. Симулятор системы "Шума"
- Слайдеры для настройки различных действий игроков
- Визуализация накопления угрозы в реальном времени
- Демонстрация эскалации угрозы с появлением разных типов зомби
- Предупреждения о приближении коллапса территории

### 3. Калькулятор территориального контроля
- Интерактивная схема базы и аванпостов
- Возможность размещения структур на карте
- Расчет эффективности буферных зон
- Визуализация снижения шума через контроль территорий

### 4. Система прогрессии навыков
- Древо навыков с визуализацией зависимостей
- Интерактивные элементы для прокачки через использование
- Визуализация времени изучения чертежей
- Примеры крафтовых рецептов для разных уровней

## Пользовательский опыт:
- Все компоненты работают без перезагрузки страницы
- Плавные анимации переходов между состояниями
- Адаптивный дизайн для мобильных устройств
- Контекстная помощь и подсказки для сложных механик
